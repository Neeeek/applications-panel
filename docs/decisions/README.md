# Decisions

One file per meaningful choice: `NNNN-slug.md`. Numbers are sequential and
never reused. Superseding a decision means writing a new ADR that links back —
never editing the old one.

## Format

```markdown
# NNNN. Title

**Date:** YYYY-MM-DD
**Status:** Accepted | Superseded by NNNN

## Context
What forced a choice.

## Decision
What was chosen.

## Alternatives rejected
What else was considered, and why not.

## Consequences
What this makes easy, and what it makes hard.
```
